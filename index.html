Contrôles

Implantation / contrôle

Points à nom non numérique (implantation, ouverture, contrôle) : le point mesuré (118150B_stkd) prend le prochain matricule libre à la fin du levé et le no du monument passe en description (9 118150B). La coordonnée de référence (118150B) sert au rapport de contrôle.

Mémoire des codes (par arpenteur)

Les associations confirmées dans « CODES » sont retenues sur cet appareil et proposées d'office aux levés suivants du même arpenteur.

DXF

Le DXF (AutoCAD R12, ANSI 1252) est livré dans un .zip. Pour hériter des propriétés du gabarit, créez un dessin à partir de Template-NouvLR.dwt puis insérez le DXF (INSERER, cocher Décomposer) : les couches C-… existantes gardent leurs couleurs et types de ligne.

Commandes de création de point (terrain)

Inscrites dans la description de chacun des points concernés, dans l'ordre du levé ; une commande doit être complétée avant la suivante. La distance s'écrit sur le point de départ : 526 1_2PD_1.00 puis 526 1_2PD → point à 1 m du 1er vers le 2e ; la distance sur le 2e point prolonge la ligne au-delà de celui-ci.

2PPoint milieu de 2 points (3D) 2PDPoint à une distance sur l'alignement 1-2 (3D) 2DIntersection de 2 distances, une par point ; valeur négative = à gauche de 1→2 (2D) 3PPPerpendiculaire du 3e point sur le segment 1-2, Z interpolé (3D) 4PIntersection des droites 1-2 et 3-4 (2D) 3CCentre du cercle par 3 points (2D). Avec .6 sur le 1er point (231 1.6_3C, puis 231 1_3C) : le cercle est dessiné et son centre calculé (ex. Z d’un radier à inscrire) RECT4e point d'un rectangle (3 points, coin au milieu)

Le point créé prend le prochain numéro libre, le code des points utilisés avec l'attribut CALCUL, et est inséré après le dernier point utilisé. Les commandes sont retirées des descriptions dans le _modif. Pour les fonctions 2D, l'élévation est la moyenne des points ; elle se change dans la fiche du point (moyenne, un point ou une valeur).

Codes de contrôle (string Leica CS20)

.1Début de ligne .2Fermer la forme (retour au premier point) .3Début de courbe / spline (arc 3 pts) .4Fin de courbe .5Point dans la courbe .6Cercle par 2 ou 3 points : .6 sur le 1er, les suivants du même string sans contrôle (ou .6) .7Continuer la ligne (même effet qu'aucun code) _Liaison multiple sur un même point : 526 1.2_2.1 ferme le string 1 et débute le string 2 ; 181 1_186 1.1 continue le 181 et débute le 186 (double Pcode). Autant de liaisons que voulu.

Format lu : Matricule,Est,Nord,Élév,Description où la description est Pcode String.Contrôle [attributs], ex. 526 1.1. Le fichier _modif est toujours écrit au format P,N,E,Z,D (Point, Nord, Est, Élév., Description), sans ligne d'en-tête, quel que soit le format lu. Il contient les descriptions corrigées, les coordonnées des points inversés et les points calculés (rectangle), insérés juste après le dernier point de leur ligne.

Le fichier d'origine n'est pas modifié : les nouveaux codes vont dans le _modif.txt. Chaque changement est journalisé et s'annule avec Annuler ou Historique.

Historique des corrections

La plus récente en haut. « Annuler » retire seulement cette correction ; si une correction plus récente touche les mêmes points, elle est annulée aussi (indiqué sur la ligne).
